# ReservaMaster CRM v2.0

Sistema inteligente de gestión de reservas para hostelería desarrollado como proyecto académico.

## Demo Online

https://crm-reservas-demo.vercel.app

## Funcionalidades Implementadas

### Gestión de Reservas
- Alta de reservas
- Edición de reservas
- Eliminación segura
- Gestión de estados
- Historial completo

### Entrada Inteligente NLP
Reconocimiento automático de:

- Nombre
- Teléfono
- Fecha
- Hora
- Número de comensales
- Requisitos alimentarios

### Gestión de Mesas
- Asignación individual de mesas
- Visualización en reservas
- Exportación a CSV
- Detección de conflictos

### Sistema de Alertas
- Conflictos de mesa
- Solapamientos horarios
- Exceso de capacidad
- Eventos especiales
- Requisitos alimentarios

### Exportación
- CSV compatible con Microsoft Excel
- Compatibilidad regional España
